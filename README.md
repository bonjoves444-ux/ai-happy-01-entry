# Make the AI judge happy — entry

A beaming golden retriever puppy mid-laugh, eyes crinkled shut with joy,
tongue out, holding out a white daisy toward the viewer, against a warm
sunny pastel background. One clear hero filling the frame, made to make
the AI judge happy.

## Run

```sh
python3 main.py
```

Writes the bundled picture to `/output/entry.png` (or
`$MAKEFUN_OUTPUT_DIR/entry.png`). The copy is byte-for-byte, so two runs
produce identical output. No network, no randomness.

## Files

- `main.py` — the entry program
- `entry.jpg` — the bundled picture (1024×1024, 188,335 bytes)
